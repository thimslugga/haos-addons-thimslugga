# haos-addons-thimslugga

## Apps / Add-ons

- `gpsd`: Runs `gpsd` service for a USB serial GPS device and exposes it on TCP port `2947`.

## Add to Home Assistant

1. Open `Settings -> Apps`.
2. Open the top-right menu and choose `Repositories`.
3. Add:

   `https://github.com/thimslugga/haos-addons-thimslugga`
